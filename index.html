UT7 - Mejora y documentación de código

UT7 - Mejora y documentación de Código - Entornos de Desarrollo (1ºDAM)

Esta Situación de Aprendizaje correspondiente con la Unidad de Trabajo 7 de Mejora y documentación de código se dirige al alumnado de 1.º de DAM, en el módulo de Entornos de Desarrollo, y se centra en el desarrollo parcial del Resultado de Aprendizaje RA4: Optimiza código empleando las herramientas disponibles en el entorno de desarrollo. 

El alumnado trabajará sobre un pequeño proyecto Java proporcionado por el profesor. A partir de ese código base, deberá identificar patrones básicos de refactorización, revisar el código con un analizador, aplicar mejoras con el IDE, elaborar una prueba asociada y documentar las clases.

Apuntes de la unidad.

Temporalización
La Situación de Aprendizaje se desarrollará en 4 sesiones de 55 minutos, a lo largo de 1 semana y media.
